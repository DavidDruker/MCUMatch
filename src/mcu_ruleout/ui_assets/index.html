mcu-ruleout

Tells you when code cannot fit or run in time on a microcontroller, even in the best case. It never says that code fits. Everything runs on this computer.

Input

The function to call. It takes no arguments and sets up its own data.

Count time only inside this function, so setup code is left out.

Results

Paste a kernel, or load the example, then run a check. There are only two possible answers:

RULED OUT
Even in the best case the code needs more memory or time than the target has.
NOT RULED OUT: measure on hardware
No proof of failure was found. This is not evidence that the code fits or is fast enough.
