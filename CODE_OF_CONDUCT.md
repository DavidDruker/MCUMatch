# Code of conduct

This project follows the **Contributor Covenant, version 2.1**. The full text is at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>, and it applies here as
written.

## In short

- Be respectful. Disagree about the work, not about the person.
- Assume good faith, and give reasons others can check: a page number, a measurement, a test.
- No harassment, insults, sexualised language or imagery, or publishing someone's private
  information.
- This is an engineering project about what can be proven. "I measured this and got that" is
  always welcome, including when it shows the tool is wrong.

## Where it applies

In this repository's issues, pull requests and discussions, and anywhere someone is speaking for
the project.
